# UI and UX prompt keywords

Vocabulary of UI components, aesthetic palettes, interaction terms, and corner shapes for Stitch prompts.

## Component keywords

- **Navigation**: navigation bar, nav menu, header, breadcrumbs, tabs, sidebar, hamburger menu, dropdown menu, back button, close button
- **Content containers**: hero section, hero banner, card, card grid, tile, modal, dialog, popup, accordion, collapsible section, carousel, slider
- **Forms**: input field, text input, dropdown, select menu, checkbox, radio button, toggle switch, date picker, time picker, search bar, search input, submit button, form actions
- **Calls to action**: primary button, secondary button, ghost button, text link, floating action button, icon button
- **Feedback**: toast notification, snackbar, alert banner, warning message, loading spinner, skeleton loader, progress bar, step indicator
- **Layout**: grid layout, flexbox, sidebar layout, split view, sticky header, fixed footer, full-width, contained width, centered content, max-width container

## Adjective palettes

- **Minimal and clean**: minimal, clean, uncluttered, generous whitespace, breathing room, subtle, understated, refined, simple, focused, distraction-free
- **Professional and corporate**: sophisticated, polished, trustworthy, corporate, business-like, formal, subtle shadows, clean lines, structured, organized, hierarchical
- **Playful and fun**: colorful, energetic, lively, rounded corners, soft edges, bold, expressive, dynamic, friendly, approachable, warm
- **Premium and luxury**: elegant, luxurious, high-end, dramatic, bold contrasts, sleek, modern, sharp, exclusive, boutique, curated
- **Dark mode**: dark theme, night mode, high-contrast accents, soft glows, subtle highlights, deep backgrounds, muted surfaces
- **Organic and natural**: earthy tones, natural colors, warm, inviting, cozy, textured, tactile, handcrafted, flowing, organic shapes

## Interaction and behavior keywords

- **Animations**: smooth entry animation, slide-in, fade transition, cross-fade, micro-interaction, bounce effect, skeleton loader, shimmer effect
- **Responsiveness**: responsive layout, adaptive grid, mobile-first, desktop-first, breakpoint, viewport, stacked layout, side-by-side
- **User flows**: step indicator, multi-step wizard, expandable section, collapsible panel, infinite scroll, pagination, drag and drop, swipe gesture

## Shape descriptions

- `rounded-none`: sharp, squared-off edges
- `rounded-sm`: slightly softened corners
- `rounded-md`: gently rounded corners
- `rounded-lg`: generously rounded corners
- `rounded-xl`: very rounded, pillow-like corners
- `rounded-full`: pill-shaped, circular edges
